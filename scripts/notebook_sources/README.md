مستقبلاً بدل تحرير ملف `.ipynb` مباشرة.

### فلسفة النسخ 2 و3 — «لا عمليات خلفية، لا subprocess، استيراد فقط»

النسخة الأولى كانت تُطلق التدريب كعملية خلفية مستقلة عن النواة (start_new_session)،
مع مراقب نسخ دائم إلى Drive وحلقة انتظار لساعات — وهي أنماط تصنفها سياسة الطبقة
المجانية في Colab «استخداماً غير مسموح» فتقطع الجلسة فجأة (Runtime disconnected).
النسخة 2 أزالتها كلها، والنسخة 3 ذهبت خطوة أبعد وألغت أيضاً البيئة المعزولة
وأي تشغيل بايثون بعملية ابن: التدريب والاستدلال وخط البيانات والرفع تعمل كلها
**داخل نواة الدفتر نفسها بالاستيراد المباشر**:

| النمط القديم | البديل في النسخة 2 → 3 |
|---|---|
| تدريب بعملية خلفية مستقلة + ملف PID | التدريب **داخل نواة الدفتر نفسها** (الخلية 12): `import train` ← `Trainer(...).train()` مباشرة |
| مراقب نسخ دائم إلى Drive (حلقة sleep) | غلاف حول `torch.save` داخل النواة ينسخ كل نقطة إلى Drive لحظة حفظها (بلا أي خيط/عملية إضافية) |
| خلية «انتظار الاكتمال» (حلقة 11 ساعة) | حُذفت — النواة مشغولة بعمل حقيقي أصلاً أثناء التدريب |
| خلايا البيانات تجلب من 5 مصادر ثم تقطّع وترمّز (ساعات) | خلية واحدة تنزّل **أرشيفاً جاهزاً** `rafidain_current_sources_ready.tar.gz` (4.89GB، 56,856 مقطع Opus / 387.8 ساعة) وتفكّه مباشرة — بلا إعادة تنزيل من المصادر ولا إعادة معالجة |
| استدعاء سكربتات بأوامر سطرية + بيئة venv معزولة + تشغيل بايثون بعملية ابن | **كل منطق المشروع يعمل داخل النواة بالاستيراد المباشر** (النسخة 3): `SEED_TRAIN.Trainer` للتدريب، `SEED_INFER.main` للتحقق، `PIPELINE.cmd_prefetch/cmd_export` لخط البيانات، `HfApi` للرفع — **صفر subprocess لمنطق المشروع**؛ الحزم تُثبَّت في نواة الجلسة نفسها |
| تنزيل الأرشيف من الصفر كل جلسة | تنزيل **قابل للاستئناف** (`curl -C -`) + تحقق الحجم الدقيق بالبايت قبل الفك + بصمة `.ready_archive_ok` تمنع أي إعادة + نسخة Drive تُستعمل إن وُجدت |

الفحوص التي يجريها المنشئ آلياً: صحة JSON وnbformat، صحة نحو كل خلية كود، تسلسل
الترقيم العربية ١–١٨، ثوابت خلية الإعداد (مسارات الأرشيف وروابطه)، **منع أنماط
الخلفية نهائياً** (فحص start_new_session/setsid/nohup/PID/while-True)، وجود
تنزيل-الاستئناف وتحقق الحجم والبصمة، واستيراد المدرب والاستدلال كوحدات.
