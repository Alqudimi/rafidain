# مصادر بناء دفترَي التدريب

الدفتران في جذر المستودع مبنيان من هذه المصادر — استخدمها لإعادة التوليد أو التعديل
مستقبلاً بدل تحرير ملف `.ipynb` مباشرة.

## دفتر RunPod — `runpod_cells/`

33 ملفاً مرقّماً (`00`–`32`)، ملف واحد لكل خلية بالترتيب نفسه الذي يظهر في
`rafidain_runpod_training.ipynb`: ملفات `NN_md_*.md` خلايا توثيق، و`NN_code_*.py`
خلايا كود. فحص صحة السكربتات المضمّنة داخل الخلايا:

```bash
python3 check_embedded.py
```

## دفتر Google Colab — `colab_cells_a/b/c.py`

ثلاث وحدات تصف الخلايا كسلاسل نصية (`CELLS_A` + `CELLS_B` + `CELLS_C`)، يجمعها
منشئ الدفتر ويتحقق منه تحققاً كاملاً (JSON، صحة نحو كل خلية كود، تسلسل الترقيم،
ثوابت خلية الإعداد، ومطابقة regex استخراج خط البيانات مع سكربت المستودع الفعلي):

```bash
python3 build_colab_nb.py   # يعيد توليد rafidain_colab_training.ipynb في جذر المستودع
```

## اختبار منطق الخلايا الحساسة

```bash
python3 test_notebook_logic.py   # تشغيل جاف: مراقب مزامنة Drive، الاسترجاع، تحليل السجلات، الإعداد
```

> ملاحظة: هذه المجلدات مستثناة من ruff عمداً — كود الخلايا يعتمد أسماء معرّفة عبر
> الخلايا (ليست وحدات مستقلة)، ويراقَب صحتها بالفاحصات أعلاه.
