# أدوات بحث البيانات العراقية على Hugging Face

السكربتات التي استُخدمت في دورة البحث عن «بيانات عراقية نظيفة ومرتبة» (طلب الإصدار ٢.١):
**مسح شامل ← استقصاء المرشحين ← قياس فعلي بالتنزيل ← قرار إضافة/استبعاد** — كلها تستعلم
واجهات Hugging Face العامة مباشرة (API + datasets-server) وتطبع تقارير JSON.

## السكربتات بالترتيب المنطقي

| السكربت | الدور |
|---|---|
| `hf_scan.py` | مسح API مجموعات Hugging Face بحثاً عن أي كلام عربي/عراقي (بحث نصي + تصفية) |
| `hf_probe.py` | استقصاء كل مرشح: قائمة الملفات، الأحجام، عدد الصفوف، الأعمدة |
| `hf_lang_stats.py` | إحصاءات اللغات لكل مجموعة (عدد صفوف كل لغة + أحجام ملفات parquet) |
| `hf_iq_measure.py` | قياس الجزء العراقي من المرشحين عبر نقطة `/filter` + أخذ عينات صوتية فعلية |
| `lahgtna_iq.py` | قياس جزء `iq` من Lahgtna v2: عدّ الصفوف + عيّنات مدة ← تقدير الساعات |
| `measure_lahgtna.py` | أعداد لغات دقيقة (قراءة أعمدة parquet عبر طلبات HTTP مُجزّأة) + عيّنات مدة |
| `measure_lahgtna_fast.py` | تقدير سريع لجزء iq (أعداد split الاختبار الدقيقة + عيّنات `/rows`) |
| `iraqi_pipeline_v3.py` | **خط البيانات النهائي (v3) المستقل** — نفسه المضمّن بايتاً بايتاً في سكربتات التثبيت الثلاثة |
| `test_pipeline_v3.py` | اختبارات منطق الخط (البيان المضمّن، مصادر small، مسار prep) |

## نتيجة البحث — ما أُضيف في v2.1

| المصدر | الحجم | الوصف |
|---|---|---|
| `lahgtna-iq` | ~10,746 مقطعاً / ≈50 ساعة | الجزء العراقي (الموسوم `iq`) من Lahgtna v2 — 16kHz أحادي مع نصوص لهجية عراقية أصيلة |
| `kharrufa` | 450 مقطعاً / ≈1.1 ساعة | Iraqi Dialect TTS Corpus (الجزيء `ar-IQ_hayder`) — تسجيلات استوديو 44.1kHz بنصوص مشكولة كاملة (CC BY 4.0) |

## ما استُبعد بعد الفحص الفعلي

| المرشح | سبب الاستبعاد |
|---|---|
| MADIS5 | لا يوجد فيه جزء عراقي أصلاً |
| moaead/dialectal-arabic-voices | فلسطيني فقط |
| hnaalbhadly6/youssef | نسخة مطابقة لما هو مضمّن لدينا |
| Falah | 130 مقطعاً فقط لكل اللهجات — غير مجدٍ |
| LDC Iraqi | يتطلب ترخيصاً مدفوعاً |
| Kaggle SARA | يتطلب تسجيل دخول ولا يُجلب برمجياً |

> التشغيل: `python3 <script.py>` من هذا المجلد. لا تحتاج رمز دخول — كل الاستعلامات عامة.
