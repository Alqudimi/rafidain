# أدوات بحث البيانات العراقية على Hugging Face

السكربتات التي استُخدمت في دورة البحث عن «بيانات عراقية نظيفة ومرتبة» (إصدار ٢.١):
**مسح شامل ← استقصاء المرشحين ← قياس فعلي بالتنزيل ← قرار إضافة/استبعاد** — كلها
تستعلم واجهات Hugging Face العامة مباشرة (API + datasets-server) وتطبع تقارير JSON.
النتائج النهائية ومنهجية القرار موثّقة في [DATA_SOURCES.md](../../DATA_SOURCES.md).

## السكربتات بالترتيب المنطقي

| السكربت | الدور |
|---|---|
| `hf_scan.py` | مسح API مجموعات Hugging Face بحثاً عن أي كلام عربي/عراقي (بحث نصي + تصفية) |
| `hf_probe.py` | استقصاء كل مرشح: قائمة الملفات، الأحجام، عدد الصفوف، الأعمدة |
| `hf_lang_stats.py` | إحصاءات اللغات لكل مجموعة (عدد صفوف كل لغة + أحجام ملفات parquet) |
| `hf_iq_measure.py` | قياس الجزء العراقي من المرشحين عبر نقطة `/filter` + أخذ عينات صوتية فعلية |
| `lahgtna_iq.py` | قياس جزء `iq` من Lahgtna v2: عدّ الصفوف + عيّنات مدة ← تقدير الساعات |
| `measure_lahgtna.py` | أعداد لغات دقيقة (قراءة أعمدة parquet عبر طلبات HTTP مُجزّأة) + عيّنات مدة |
| `measure_lahgtna_fast.py` | تقدير سريع لجزء iq (أعداد split الاختبار الدقيقة + عيّنات `/rows`) |
| `iraqi_pipeline_v3.py` | **خط البيانات النهائي (v3) المستقل** — نفسه المضمّن بايتاً بايتاً في سكربتات التثبيت الثلاثة |
| `test_pipeline_v3.py` | اختبار تكاملي يداني للخط (يحتاج إنترنت + ffmpeg؛ ويحتاج `KHARRUFA_ZIP` لأجزاء الخرّوفا وإلا يتخطى بنظافة) |

## التشغيل

```bash
python3 hf_scan.py            # لا يحتاج رمز دخول — كل الاستعلامات عامة
python3 test_pipeline_v3.py   # تكامل كامل (اختياري)
```
